# FastH3: the dense attention backend is inert on the contract graph (2026-09-27)

The owner asked whether FastH3's look comes from the attention kernel, and
whether sage against kitchen attention matters. Core's VSA node
(`BlockSparseAttention`, selection "vsa") uses the model's dense backend
(`ModelAttentionBackend`) only as a fallback: outside its step window, on
dense blocks, and under `min_tokens`. The contract graph keeps 20% from the
first step, lists no dense blocks, and runs sequences far above
`min_tokens`.

**Arms:** `h3_probe_t2v_fasth3_8step_contract_savelat` with
`ModelAttentionBackend.attention` set to "pytorch attention" (bf16) instead
of "comfy kitchen attention" (int8), on `t2va_look_anchor` and
`t2va_slapstick_moving_piano` at 730451892 (`bench/fasth3_bf16rows_arms.json`;
rows in `2026-09-27_fasth3_bf16rows.jsonl`). The references are the follow-up
rerun's `look_anchor__fasth3` and `slapstick_moving_piano__fasth3`, rendered
the night before in a different server process.

**Result: the saved final latents are bit-identical to the int8-backend
renders on both scenes** (`torch.equal`). Tone matches to every printed digit
(`2026-09-27_fasth3_bf16rows_tone.json`). The patch landed (node 58 carries
"pytorch attention" in each row), and no row flags a suspected cache hit.

- **The dense backend never executes in these renders.** The fused VSA kernel
  handles every attention call, the exactly-computed text and sink rows
  included. So the "dense rows run on kitchen int8 attention" line in
  `2026-09-26_fasth3_weights.md` does not describe this graph at these
  settings.
- **So the backend is ruled out as the source of FastH3's look.** Sage
  against kitchen is moot for FastH3 as well: our sage node would sit in the
  same unused fallback.
- **The one attention component left is core's fused VSA kernel,** which is
  int8 and cannot be swapped by a setting. Testing it needs code. That is not
  queued.
- **Side result:** FastH3's contract render reproduces bit for bit across
  server processes at this seed.
